Duka One for Homey

Control Duka One ventilation units from Homey over your local network.

FEATURES

- Fan control: on/off, low, medium, high and manual speed.
- Ventilation mode: in/out (heat recovery), in (supply air) and out (exhaust air).
- Humidity sensor.
- Filter alarm and remaining filter lifetime, with a maintenance action to reset
  the filter timer.
- Flow cards for mode, speed, manual speed and filter reset, plus triggers for
  mode changes and filter alarms.
- Network discovery during pairing, with manual device ID and IP entry as a
  fallback.

REQUIREMENTS

- Homey Pro (Early 2023 or later) or Homey Self-Hosted Server, with LAN access.
  The app does not work on Homey Cloud.
- The Duka One unit on the same network, or reachable through a route.
- The device ID from the Duka One mobile app. The default password is 1111.

The app is not affiliated with Duka Ventilation.
